# Personal website

[harmanpreet93.github.io](https://harmanpreet93.github.io/) is a static site served by GitHub Pages from the repository's `master` branch and root directory.

There is no build step: content lives in `index.html`, and the browser loads `assets/css/main.css` directly.

For a local preview, run `python3 -m http.server 8000` in the repository and open `http://localhost:8000/`.
